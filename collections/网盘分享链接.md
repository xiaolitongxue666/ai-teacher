## 降级排查

链接打不开时按这个顺序处理：

1. **换官方域名**。把 `pan.quarkn.xyz/s/<id>` 换成 `pan.quark.cn/s/<id>`；`wpss.best/res/<id>` 无法换，只能靠两个源互备。
2. **跑探针**，确认是链接问题还是网络问题：
   ```bash
   python scripts/check_links.py --only collections
   ```
3. **查 `data/resources.json`**。对应条目的 `note` 里可能有备用入口。
4. **提 issue**，带上条目 `id`。

### 快速提取真实地址

```bash
python -c "import urllib.request;print(urllib.request.urlopen(urllib.request.Request('https://pan.quarkn.xyz/s/668920790b03',headers={'User-Agent':'Mozilla/5.0'})).geturl())"
```

原理：`urlopen` 会自动跟随 302 与 `<meta refresh>` 跳转，`geturl()` 返回最终地址。
