## 状态说明

| 状态 | 含义 | 处理建议 |
| --- | --- | --- |
| `ok` | HTTP 2xx，可直接访问 | 直接用 |
| `blocked` | 站点反爬，脚本探测返回 403/429 | 用浏览器打开，通常正常 |
| `dead` | 域名不存在或站点已关停 | 别用了，找替代 |
| `unreachable` | DNS 正常但本机连不上 | 需要代理，或换网络 |
