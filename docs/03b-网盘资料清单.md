**爆笑初中9科是最大的一包，21943 个文件、1534 次请求、约 11 分钟才跑完。** 早期版本用 400 次预算上限，把它截断成 6899 —— 这是严重低估，真实值是这个数字的 3 倍多。现在默认预算提到 2000，并在数据里为这一条单独设了 `share_request_budget`。

顺带一个数据质量问题：这个分享里有 4 个文件的扩展名被文件名截断污染，统计里出现 `.求三个字母之比mp4`、`.平移`、`.投影` 这种键。这是分享方上传时文件名超长被截断导致的，文件本身能正常下载，但按扩展名做统计会失真。

**统计口径的一个坑**：如果某页请求超时，不能当成「目录到底了」。早期版本这么处理过，同一分享两次统计相差 40 个文件。现在单页失败会重试 3 次，仍失败则记 `share_tree_failed_pages` 并标 `share_tree_incomplete: true`。

**提取码**：9 个夸克分享中 2 个需要提取码——`primary_1000_words`（`YhRG`）与 `phonics_270`（`ab8M`），码记在 `data/resources.json` 的 `password` 字段，带码实测均通过。其余无需提取码。

## 入口类型说明

清单里的链接分两类，用途完全不同：

| 类型 | 特征 | 风险 |
| --- | --- | --- |
| **官方直链** | 域名就是网盘官方域名（`pan.quark.cn`、`pan.baidu.com`） | 低。链接失效只说明分享被取消 |
| **第三方中转** | 域名是短链/跳转站（`pan.quarkn.xyz`、`wpss.best`、`v.v8l.cn`、`pan.powersharex.com`、`pan.nameishare.com`、`pan.quarket.xyz`） | 中。站点本身可能随时消失，且可能插广告或诱导下载 |

**本仓库统一记录官方直链**，第三方中转域名单独列在 [collections/网盘分享链接.md](../collections/网盘分享链接.md) 作为「入口别名」。这样某天中转站挂了，你不会以为是资料没了。

判断方法：

```bash
python -c "import urllib.request;print(urllib.request.urlopen(urllib.request.Request('https://pan.quarkn.xyz/s/668920790b03',headers={'User-Agent':'Mozilla/5.0'})).geturl())"
# 输出 https://pan.quark.cn/s/668920790b03
```

**实测目录与原始文案的差异**

「900 节」这个数量是准确的——夸克分享目录实际有 910 个条目，其中 909 个是 mp4。但「1-6 年级全覆盖」站不住：

| 年级标记 | 条目数 |
| --- | --- |
| 仅 L6 | 111 |
| L5 + L6 | 62 |
| L4 + L5 + L6 | 24 |
| L3 + L4 + L5 + L6 | 31 |
| L2 - L6 | 1 |
| L1 - L6 全年级适用 | 3 |
| 无年级标记 | 678 |

标记是「L1、2、3、4、5、6」这类范围语法，一个文件可同时覆盖多个年级，所以不能把单个 L 的计数相加。

真正碰到低年级的只有最后两组共 4 条：「神奇的手指计算器」「图形法巧解难题」「趣味题」「借 1 还 1 法巧解计算题」——都是全年级通用的技巧题，不是 1-2 年级的课标内容。

按主题统计也能看出重心：

| 主题 | 条目数 |
| --- | --- |
| 巧求面积 | 150 |
| 图形 | 38 |
| 分数 | 34 |
| 方程 | 12 |
| 规律 / 鸡兔同笼 | 各 10 |
| 立体图形 / 组合 / 容斥 | 各 9 |
| 行程 / 盈亏 | 各 8 |
| 圆的运动 / 年龄 | 各 7 |
| 巧求周长 / 抽屉 | 各 6 |
| 工程 / 排列 | 各 5 |
| 牛吃草 / 数论 | 各 4 |

「拉窗帘模型」「蝴蝶模型」「一半模型」「割补法」「旋转法」「牛吃草」「鸡兔同笼」「抽屉原理」——这些是**小学奥数/思维训练**的典型专题，不是课标内的几何。

**怎么用**

- **1-3 年级**：这套课基本用不上。低年级的图形认知需求，用 [NRICH](https://nrich.maths.org) 或 [Math Playground](https://www.mathplayground.com) 更合适。
- **4-6 年级**：可以作为专题突破材料。挑「巧求面积」「立体图形」「圆的运动」这几类，这些确实是校内考试和竞赛的高频难点。
- **不要当同步课用**。它不按教材章节编排，是按解题模型编排的。

**为什么动画形式仍然值得**

纸质材料讲旋转、展开、截面时只能画成一组静态图，孩子要在脑子里把它们连起来——这一层认知负担恰恰是「数学不开窍」的来源。动画把过程直接演出来，省掉的是这层拼接。

这跟「视听输入优于文本输入」是同一个原理，只是对象从语言换成了空间关系。

**使用建议**

1. **同一集看两遍**。第一遍看过程，第二遍暂停在关键帧，让孩子说出「接下来会变成什么」。
2. **第三遍让孩子讲给你听**。能讲清「为什么」才算懂，画对答案不算。
3. **看完拿纸笔画一遍**。手动画一次，比刷十道题有效。
4. 那 1 个 `电子档资料.zip` 是配套讲义，建议先解压看一遍再决定从哪节开始。

**它做什么**

从国家中小学智慧教育平台（`basic.smartedu.cn`）解析电子课本的 PDF 地址并批量下载，支持：

- 一次输入多个课本预览页网址，批量下载，自动跳过已完成的；
- 用课本名称自动命名文件；
- 下载完成后自动给 PDF 加书签，方便跳转；
- 可按「学段、学科、年级」组合搜索资源；
- 可选填 Access Token（部分资源需要）。

## 失效与降级处理

第三方短链域名的稳定性不可预期。当你发现某个链接打不开时，按这个顺序排查：

1. **换官方域名**。把 `pan.quarkn.xyz/s/xxx` 换成 `pan.quark.cn/s/xxx` 试试。
2. **跑一遍探针**。`python scripts/check_links.py --only collections` 会告诉你到底是链接没了还是网络问题。
3. **看 `note` 字段**。有的条目在 `note` 里写了备用入口。
4. **提 issue**。标上条目 `id`，方便定位。
