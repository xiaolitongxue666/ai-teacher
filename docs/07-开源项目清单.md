## 几个值得单独说的项目

### `HKUDS/DeepTutor` — 最接近「AI 老师」的一个

港大数据智能实验室出品，Apache-2.0，57,188 star，v1.7.2。定位是「终身个性化辅导」，agent-native 学习工作台，不是刷题工具。

它本身是成品也是框架：可以直接 Docker 跑起来用，也可以照它的 capability / module 结构自己接。

**一个必须先知道的边界**：它是 MCP **客户端**，不是 MCP server，不能直接挂进 Cursor 当工具，只能用 CLI、HTTP/SSE 或 Python SDK 驱动。完整拆解（实现链路、三层记忆、多引擎 RAG、模块化分发）见 [08-DeepTutor-拆解](08-DeepTutor-拆解.md)。

### `designfuchen/word-atlas` — 单词记忆里少见的工程化做法

7298 个雅思词，配英美双音、图解、以及 **FSRS 间隔重复算法**。

FSRS（Free Spaced Repetition Scheduler）是目前公开算法里效果最好的间隔重复调度器之一，比 Anki 早期的 SM-2 准得多。一个词汇项目愿意接 FSRS，说明作者真的在意记忆效果，而不是做个列表页。

### `xiaoyang111222/cn-math-taxonomy` — 用来定位薄弱环节

小学数学到高中、英语三年级到高中、初中物理的知识图谱。

它的用处不是「学」，是**「诊断」**。孩子某道题做错，顺着图谱往上找前置知识点，能定位到底是哪个环节断了。这比自己回忆「以前学过什么」可靠得多。

### `algorithm-visualizer` — 把抽象过程画出来

49k star。任意算法可以用代码描述，然后看它一步步执行。

对孩子的价值不在「学算法」，在建立「过程可以被可视化」的直觉。这和几何动画课是同一个原理：把看不见的过程演出来。

### `opendatalab/MinerU` — 扫描版 PDF 的解法

83k star，上海 AI Lab 出品。扫描件自动 OCR，复杂版面（公式、表格、多栏）还原成结构化 Markdown。

如果你要批量处理教材 PDF 进知识库，这是本地方案里的首选。Dify 官方也直接集成了它（见 [../dify/README.md](../dify/README.md)）。

### `happycola233/tchMaterial-parser` — 教材下载的可用方案

7,746 star，MIT，Python。从国家中小学智慧教育平台（`basic.smartedu.cn`）解析电子课本 PDF 地址并批量下载。

累计下载 42,639 次，最新 v4.4（2026-10-07），Release 覆盖 6 个架构（Windows/Linux/macOS，x86_64/Arm64）。

```bash
winget install tchMaterial-parser
```

**为什么用它替代原来那条 `v.v8l.cn` 短链**：那条短链实测打开是「网盘热门资源2000T」扫码页，与教材下载器无关。这个项目源码可审、许可明确、更新活跃，作者也写明「不存储、不托管、不分发任何资源内容，所有资源均直接来自国家中小学智慧教育平台」。

如果只是临时看几页，不用装工具，直接开 `https://basic.smartedu.cn/tchMaterial/`，浏览器里能在线翻阅。

### `shaom/keyboard-island` — 打字练习做成了游戏

101 star，两个项目：Keyboard Island（96 章打字冒险）和 Sentence Post Office（句子邮局，练句子输入）。

比 TypingClub 更"游戏"，适合坐不住的孩子。

## 怎么判断一个教育资源项目值不值得用

看四个信号，按重要性排：

1. **最近一次 push 时间**。半年没动的项目，API 大概率已经失效。用 `gh repo view <owner>/<repo> --json pushedAt` 查。
2. **star 数与 issue 活跃度的比例**。星多但 issue 无人回，说明作者跑了。
3. **有没有明确的 License**。没有 License 的项目，严格来说你不能改也不能分发。
4. **README 里有没有可复现的启动步骤**。写了「clone 后运行」但没写环境要求的，通常跑不起来。

本仓库在收录时至少核实了第 1 项和第 4 项（仓库存在、描述与实际功能一致）。星数取的是实际 API 值，不是文案里写的。
