# 适合人群

按年龄和语言发展阶段划分。每个群体讲三件事：这个阶段的核心矛盾、最有效的输入形式、以及本仓库里对应的入口。

---

## 学前｜2-3 岁

**核心矛盾**：母语还没固化，大脑可以直接建立「声音信号 → 画面情境」的物理映射。

这个阶段不需要教，只需要泡。孩子听到一句外语时脑子里直接浮现画面，中间没有翻译环节——这是效率最高的状态，成人已经永久失去了这个窗口。

**输入形式**：动画片。不是教学视频，是有剧情、有画面、语速正常、配音有情绪起伏的动画。

**入口**

| 资源 | 说明 |
| --- | --- |
| [Starfall](https://www.starfall.com) | 字母与阅读启蒙，节奏慢，适合第一次接触 |
| [PBS Kids](https://pbskids.org) | 教育动画与游戏，剧情驱动 |
| [Sesame Street](https://www.sesamestreet.org/) | 语言密度高，有大量重复与韵律 |

**注意事项**

- 保护视力靠户外 2 小时，不靠减少屏幕时间。把户外写进日程，视频时间反而可以放宽。
- 不要配中文字幕。不要"翻译提问"（"这个单词是什么意思呀？"）。这一句问话就会把孩子从画面模式拽回翻译模式。

---

## 学前｜4-6 岁

**核心矛盾**：开始要认字母、练拼读，但还不能靠"背单词"。

**输入形式**：自然拼读 + 有声绘本。拼读解决"看到字母组合能读出来"，绘本解决"读出来之后知道意思"。

**入口**

| 资源 | 说明 |
| --- | --- |
| [Reading Bear](https://www.readingbear.org) | 系统自然拼读，免费，进度可控 |
| [Storyline Online](https://www.storylineonline.net) | 演员真人朗读绘本，配字幕，超音段特征真实 |
| [StoryWeaver](https://storyweaver.org.in) | 多语言绘本，可下载 PDF 打印 |
| [自然拼读作业纸 270+ 页](../docs/03b-网盘资料清单.md#phonics_270) | 可打印，反复巩固 |

**注意事项**

- 拼读是"解码工具"，不是"背规则"。270 页作业纸的意义在于**每天几页、持续几个月**，而不是一口气刷完。
- 这个阶段不要引入语法。语法要等有效词汇量到 3000 左右才有效，否则只是增加认知负担。

---

## 小学低年级｜1-3 年级

**核心矛盾**：从"听懂"过渡到"读懂"。听力词汇量已经有了，要把它转化成阅读词汇量。

**输入形式**：分级读物 + 几何图形直观认知。

**入口**

| 资源 | 科目 | 说明 |
| --- | --- | --- |
| [Oxford Owl](https://www.oxfordowl.co.uk) | 英语 | 牛津分级阅读，需注册免费账号 |
| [Free Kids Books](https://freekidsbooks.org) | 英语 | 免费电子书，可下载 |
| [**范老师几何思维课（1-3 年级段）**](03b-网盘资料清单.md#fan_geometry_900) | 数学 | 900 节动画教程，用动画把图形关系讲清楚，不靠背公式 |
| [NRICH](https://nrich.maths.org) | 数学 | 剑桥问题库，按学段分级 |
| [Math Playground](https://www.mathplayground.com) | 数学 | 数学游戏与可视化 |

**注意事项**

- 阅读要"跳一跳够得着"（i+1）。一页里生词超过 5 个，说明这本书难了，降一级。
- 几何在这个阶段的重点不是算面积，是**看得懂图形怎么拼、怎么转、怎么切**。动画课的优势就在这里——它是动态的，比纸质教材更能呈现"旋转""展开""叠加"这些过程。
- 学英语和学数学不要分先后。这两件事占用的是不同认知通道。

---

## 小学高年级｜4-6 年级

**核心矛盾**：阅读量爆发期，同时也是几何从"直观"转向"推理"的转折点。六年级前解决英语，初二之后基本没有时间补救。

**输入形式**：章节书 + 几何推理 + 盲打。

**入口**

| 资源 | 科目 | 说明 |
| --- | --- | --- |
| [Free Kids Books](https://freekidsbooks.org) | 英语 | 章节书起点 |
| [News in Levels](https://www.newsinlevels.com) | 英语 | 同一新闻三档难度，天然 i+1 |
| [Wordly Wise 3000](03b-网盘资料清单.md#wordly_wise_3000) | 英语 | K-12 学术词汇体系 |
| [**范老师几何思维课（4-6 年级段）**](03b-网盘资料清单.md#fan_geometry_900) | 数学 | 从图形认知推进到几何推理 |
| [TypingClub](https://www.typingclub.com) | 工具 | 十指盲打，越早越省事 |
| [Scratch 3.0 全套 174 节](03b-网盘资料清单.md#scratch_174) | 编程 | 用游戏动机带出逻辑训练 |

**注意事项**

- 这个阶段最容易犯的错是"学校会教"。如果学校的英语还是中英机械翻译式的教法，靠课内永远到不了自由阅读。
- 读原版书要先"突破畏惧感"：认真读完几本**薄**的原版书，比反复开始又放弃十本厚书有效。
- 几何推理的关键是把"看图说话"变成"说清理由"。让孩子口头解释"为什么这两个三角形面积相等"，比做十道计算题有用。

---

## 初中

**核心矛盾**：学科英语（用英语学其他科目）+ 理科实验的抽象化。

**输入形式**：分级新闻、仿真实验、跨学科阅读。

**入口**

| 资源 | 科目 | 说明 |
| --- | --- | --- |
| [BBC Bitesize](https://www.bbc.co.uk/bitesize) | 全科 | 英式课标，配短视频，适合用英语学学科 |
| [PhET](https://phet.colorado.edu) | 物理化学 | 可离线下载的仿真实验 |
| [Simple English Wikipedia](https://simple.wikipedia.org/wiki/Main_Page) | 通识 | 简化英语维基，i+1 阅读的理想语料 |
| [Breaking News English](https://breakingnewsenglish.com) | 英语 | 新闻分级 + 配套练习 |
| [BodyVista](https://github.com/FreedomIntelligence/BodyVista) | 生物 | 沉浸式人体解剖 |
| [Atlas of Physics](https://github.com/nathanliow/atlas-of-physics) | 物理 | AP Physics 1/C 交互式 3D 教材 |

**注意事项**

- 十岁以后母语已经固化，靠看动画片"刷"不出新语言了。这个阶段只能靠**大量、高密度的可理解输入**，让同一个词在几十种不同语境里反复出现。
- 不要再指望"背单词表"。高中阶段词义高度依赖上下文，脱离语境背释义，在真实阅读中依然反应不过来。

---

## 高中 / 成人

**核心矛盾**：应试需求与真实能力之间的落差。

**入口**

| 资源 | 用途 |
| --- | --- |
| [IELTS Atlas](https://github.com/gtiipoi/ielts-practice) | 雅思练习系统 |
| [Word Atlas](https://github.com/designfuchen/word-atlas) | 图解雅思词汇 7298 词，含英美音与 FSRS 复习 |
| [awesome-english-ebooks](https://github.com/hehonghui/awesome-english-ebooks) | 经济学人、纽约客、卫报等，含音频 |
| [Test-English](https://test-english.com) | A1-C1 分级测验，先摸个底 |
| [Longman Dictionary](https://www.ldoceonline.com) | 释义用 2000 基础词写成，查词不制造新词 |
| [YouGlish](https://youglish.com) | 按词检索真人视频语境 |

**注意事项**

- 先测再学。不知道自己在哪个级别，所有资源选择都是猜的。
- 查发音不要用 TTS。TTS 走的是「文本 → 音素 → 声学特征」流水线，模型不理解潜台词和逻辑重音，重音放错会直接干扰语义捕捉。用 YouGlish 听真人怎么说。
