# 本地资料库

已下载的小学同步课和网盘教辅按课程槽位放在 `downloads/library/`。排课先查这里，再决定要不要去网上找。

GitHub 克隆仍在 `downloads/github/`，那是代码和工具，不进这棵树。

- 目录数据：`data/library_catalog.json`（2026-11-12 扫描：2395 个系列、15606 个文件、250977666983 字节，约 233.74 GB）
- 重新生成：`python scripts/catalog_library.py`
- 查询：`python scripts/library_query.py --subject 英语 --edition 人教版 --grade 三年级 --volume 下册`

文件数和字节数只从磁盘扫描来，不要手改 JSON。

## 目录怎么读

```
downloads/library/
  小学/{学科}/{版本}/{年级}/{册}/{用途}/{系列}/
  小学/{学科}/通用/{专题}/{系列}/
  课标/{义务教育|普通高中}/{年}/文件
```

举例：

- `小学/英语/人教版/三年级/下册/同步课/renjiao_english_g3_down/` 是这一册的 B 站同步课
- `小学/数学/人教版/一年级/下册/试卷/53全优卷-2024春/` 是这一册的试卷
- `小学/数学/通用/思维专题/巧求面积/` 是范老师几何课里的一个专题，不绑某一册

用途从**系列目录名**判定，配套的 mp3 和答案 pdf 跟该系列走，不按扩展名另分一档。

| 用途 | 目录名里出现这些词 |
| --- | --- |
| 同步课 | B 站五组同步课 |
| 预习 | 预习 |
| 同步练习 | 天天练、练习帮、一遍过、课时练、课堂作业、练习册 |
| 默写背记 | 默写、背记、背诵、看拼音、必背、速记 |
| 试卷 | 全优卷、测试卷、名卷、考卷、测评卷 |
| 复习冲刺 | 期末、归类复习、冲刺、小升初、复习 |
| 教材解读 | 教材全解、一点通、课堂笔记、导学案、考点梳理、答案 |
| 专项 | 写作、阅读、口算、实验、语法、计算 |
| 字帖 | 字帖、描红 |

对不上这些词的系列用途是「其他」。2026-11-12 扫描时这类文件是少数（语文 54、数学 76、英语 6、科学 75、道法 26）。

同一册如果有两个年份（`24秋` 和 `25春`），系列目录名会带上年份，不会互相覆盖。

## 版本

- 语文、道法在国家审定目录里只有统编。路径里写「人教版语文」的，落在 `统编版`。
- 数学按包内版本：人教版、北师大版、苏教版、西师大版、冀教版、青岛版、BJ版、通用版。
- 科学按包内版本：教科版、冀人版、青岛版、人教鄂教版、大象版、苏教版、湘科版。
- 英语从路径里的「人教 / PEP / 外研」取。视频侧外研是三起点，主编留空，见 [11-在线视频课程](11-在线视频课程.md)。
- 小学英语从三年级起。一二年级没有国家审定的英语教材。

## 不拆开的材料

文件名里能看出单册（`一下`、`1下`、`西1数上`、`3B`）的，按文件拆到对应年级册。看不出单册的，留在一个范围目录里，不复制到六个年级。

| 路径 | 含义 |
| --- | --- |
| `一至六年级`、`三至六年级` | 文件名没有单册，父目录是一个年级段 |
| `跨年级` | 整套材料没有年级 |
| `全册` | 没有上下册 |
| `上下册` | 一份材料同时覆盖上下册 |

查询某一册时，覆盖该年级的范围目录、以及没写年级的目录，会一起列出来。上册不会混进下册。

## 不能当同步课

- **范老师几何课**在 `小学/数学/通用/思维专题/`。910 个 mp4 按解题模型编排（巧求面积等），文件名里的 `L5、6` 只是适用年级标记，不是课标同步课。
- **自然拼读**在 `小学/英语/通用/自然拼读/`，**幼小衔接数学**在 `小学/数学/通用/幼小衔接/`，**小学 1000 词**在 `小学/英语/通用/词汇/小学1000词/`。
- **课标**在 `课标/`。61 个 PDF，按义务教育 / 普通高中和修订年分，是标准文本，不是课时。

## 搬迁

已有文件用 `python scripts/migrate_library.py` 预览，`--apply` 才同盘改名。未分类超过 5%、两条体积不同的文件落到同一路径、或路径长到 250 字符，预览会停住。体积相同的重复文件只留一份（本次有 6 个，是冀教版《七彩练霸》下册在两个目录里各有一份）。

以后的夸克下载和 B 站下载走 `scripts/downloads/library_layout.py` 的同一套路径。重跑时按新路径判断文件是否已在，不会把这 15606 个文件再下一次。
