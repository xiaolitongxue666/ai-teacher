# 在线视频课程（按教材版本）

同一本教材在不同流媒体平台上有大量配套课程，但标题普遍写得混乱：版本对不上、年级串台、册别混淆、集数虚标。这份文档**按国家审定教材的版本 × 学科 × 年级 × 册别建立矩阵**，每一格给一个核实过的 B站课程。

- 数据源：`data/resources.json` 的 `videos` 段（61 条）
- 重新检索：`python scripts/search_bilibili_courses.py --write`
- 只核验入口可达性：`python scripts/check_links.py --only videos --write`
- 检索与核验时间：2026-11-09 14:50；北师数学六上与外研 8 格于 2026-11-10 11:20 复核更新

> 每条都调过 B站 `view` 接口，`分P数`、`时长`、`播放量` 是接口返回的实测值，不是标题声称。

## 先说三件容易踩错的事

### 1. 分类基准是国家审定教材，不是 B站 的标签

矩阵来自国家中小学智慧教育平台的教材目录（`s-file-1.ykt.cbern.com.cn` 的 `part_100/101/102.json`），共 3000 条记录，`tag_list` 里带 `zxxbb`（版本）/ `zxxxk`（学科）/ `zxxnj`（年级）/ `zxxcc`（册别）/ `zxxxd`（学段）五个维度。

筛出小学语数英后是 **59 格**，加上 1 条地方教材，检索当时是 60 条。2026-11-10 补上外研三起点四年级上册后，`videos` 段为 **61 条**。

### 2. 语文没有「人教版」，只有统编版

平台里小学语文 12 条记录**全部是统编版**。所谓「人教版语文」「部编版语文」指的是同一套教材——2017 年起全国统一使用统编版，人民教育出版社只是出版方。

所以语文表只有一列版本。

### 3. 小学英语从三年级起，二年级没有国家审定教材

平台上小学英语共 23 个版本，**没有任何一个覆盖二年级**。国家审定的小学英语教材统一从三年级开始。

你提供的「外研社新交际英语二年级上册」（`BV1eFmAY4Eq4`）属于外研社的地方/校本教材，不在国家审定目录内，因此单列在最后，并注明了这一点。

另外，外研社版在国家审定目录里按主编分成三个（孙有中 / 刘兆义 / 张祖春），覆盖年级不同，其中刘兆义主编覆盖三到六年级、缺四年级上册。B站标题不写主编，无法逐条对应，所以下表按「外研三起点」统一标注为 8 格，`editor` 留空。

## 怎么用

### 优先看分P数，不要看标题的集数

标题里的「全98集」「全62集」普遍虚标。实测 30 条带集数的标题中，**只有 3 条真正对得上**。判断覆盖度看 `分P数` 那一列。

### 上下册合并的合集要按分P名定位

有 12 条标题同时含「上册」「下册」，它们是合并合集，实际覆盖两册但分P 混在一起。点进去看分P 列表，按 `第X单元` 或 `Unit X` 定位。

### 一条视频不等于一学期

分P数 20-50 的，通常是「同步精讲」，每分P 约 15-30 分钟，能覆盖一学期。分P数 5-10 的，多半是「课文朗读/跟读」，只适合磨耳朵，不能替代讲解。

### 想下载就交给 `yt-dlp`

```bash
python scripts/download_video.py "https://www.bilibili.com/video/BV1HA411W7jj"
```

默认 1080p + 字幕，落到 `downloads/`。B站字幕需要登录态，无登录能下视频但拿不到 `.srt`。

## 检索方法本身（可复现）

```bash
python scripts/search_bilibili_courses.py --grid        # 看矩阵，不检索
python scripts/search_bilibili_courses.py --only 数学    # 只跑一科
python scripts/search_bilibili_courses.py --write       # 全量检索并回写
```

三条通道的实测成功率，决定了脚本为什么这么设计：

| 通道 | 成功率 | 拿到什么 |
| --- | --- | --- |
| `search.bilibili.com/all` SSR | 8/8 | 40-46 个 bvid + 标题 |
| `api.bilibili.com/x/web-interface/view` | 31/32 | 分P数、时长、UP 主、播放量 |
| `x/web-interface/wbi/search/type` | 5/8 | 20 条完整元数据 |

`space/wbi/arc/search` 与 `yt-dlp bilisearch` 都是 `412`，不要试。

标题匹配有三道硬门槛，缺一条就会错：

1. **出版社必须出现**——否则「北师大版六年级英语」会匹配到「湘少版六年级英语」
2. **册别必须对**——否则「四年级下册」会匹配到「四年级上册」
3. **其它学科名不能出现**——否则「北师大版四年级英语下册」会匹配到「北师大版四年级数学下册」
